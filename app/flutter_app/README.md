# CineStream - Flutter Android Application

A high-performance cinematic streaming mobile application mirroring all CineStream features:
- **Spotlight Hero Banner**: Trending movies & TV shows with real-time TMDB integration.
- **Embedded Video Streaming Player**: Hardware-accelerated WebView player with stream server switching (FMOV Primary, Vector HD, Core, 4K Ultra) and theater dim mode.
- **TV Series Episode Drawer**: Season selectors, episode navigation, still thumbnails, and runtimes.
- **My List & Watch History**: Persistent local bookmarking and history tracking using `SharedPreferences`.
- **Explore & Real-time Search**: Search across movies, TV series, and anime with instant suggestions.

## How to Build the APK on FlutLab.io (1-Click)

1. **Download/Zip the Flutter Project**:
   - The project is located at `app/flutter_app`.
   - Zip the contents of this folder (`pubspec.yaml`, `lib/`, `android/`).
   *(Or download `cinestream-flutter.zip` directly from the project directory)*.

2. **Open FlutLab.io**:
   - Go to [https://flutlab.io](https://flutlab.io) and log in or create a free account.

3. **Import Project**:
   - Click **+ New Project** -> **Upload Zip**.
   - Select your zip file containing this project.

4. **Build APK**:
   - In FlutLab's top toolbar, choose **Build Project** (or press the hammer/build icon).
   - Select **Android (.apk)** as the target.
   - Once the build finishes (takes ~1-2 minutes), click **Download APK** or scan the QR code to install directly on your Android phone!
